# Для Евочки — 18

Личный сайт-квест к восемнадцатилетию Евы, 5 ноября. Внутри — 18 вопросов по переписке Евы и Кости, поздравление от Кости и страница с настоящими ответами и воспоминаниями.

Сайт полностью на русском. В нём нет оценок и проверки во время игры: Ева просто выбирает вариант, и следующий вопрос открывается автоматически.

## Запуск

Требуется Node.js 20.19+ и npm или pnpm.

```bash
npm install
npm run dev
```

Адрес локального сервера появится в терминале (обычно `http://localhost:5173`).

Для проверки и сборки:

```bash
npm run typecheck
npm run lint
npm run test
npm run build
```

Или `pnpm install` и `pnpm dev`. `node_modules` и файлы сборки не входят в архив.

## Экраны и поведение

- **Главная:** открытка «18» и слайдер «Начать». Если прогресс уже есть, появляется «Продолжить». После полного прохождения можно начать заново; поздравление доступно отдельной ссылкой.
- **18 вопросов:** четыре главы по переписке, четыре варианта на каждый вопрос, автоматическая смена без подсветки выбора. Прогресс сохраняется локально. Карточка вопроса остаётся на экране, меняется только содержимое.
- **Поздравление:** личное письмо от Кости, короткий розовый салют с двух сторон (без анимации при `prefers-reduced-motion`) и слайдер «Узнать ответы».
- **Воспоминания:** выбор Евы, исходный ответ, пояснение и блок «Подумать» для каждого вопроса. Совпадения выделяются только мягким цветом, без «верно/неверно».

Прогресс и настройки хранятся только в `localStorage` браузера. Никакие ответы не отправляются на сервер. Музыки, фотографий и внешней аналитики нет.

## Слайдеры

Реализация в `src/components/ui/SlideAction.vue`, геометрия в `src/utils/slideGeometry.ts`.

- В покое **ширина и прозрачность заливки равны нулю**.
- При движении заливка идёт от левого края **на 5 px правее правого края ползунка**; в конце обрезается по дорожке. Подпись геометрически центрирована по ширине всего слайдера.
- Если отпустить раньше порога, ползунок и заливка возвращаются в исходное положение. При достижении 95% пути действие завершается автоматически.
- С клавиатуры кнопка доступна через Enter и пробел.

## Живой фон и стекло

Фон реализован в `src/styles/base/global.css`: три крупные **линейные** градиентные плоскости непрерывно перемещаются, меняют масштаб и прозрачность с разными периодами. Это не отдельные круги, а плавные переходы цвета по всему экрану. Для светлой и тёмной тем заданы разные оттенки. Светлая тема использует более белую основу и динамичные пастельно-розовые переходы.

Стеклянные поверхности используют CSS Custom Properties из `src/styles/tokens/index.css`. В настройках можно выбрать тему и изменить прозрачность и размытие. Анимации отключаются по `prefers-reduced-motion` или соответствующему пользовательскому переключателю.

## Нижняя область Safari на iPhone

Раньше `html`, `body` и скрипт ранней установки темы задавали отдельный плоский фон `#fff6fa` — он мог выглядеть как прямоугольник под адресной строкой на iOS 26. В этой версии дополнительная однотонная заливка удалена: у `html` фон задан тем же градиентом (`--page-canvas`), что и у `.ambient-layer`; `body` прозрачен. Цвет `theme-color` остаётся только в качестве запасного цвета для браузеров, которые его поддерживают. Дополнительно добавлен невидимый `safari-toolbar-transparent-hint` (6 px, `position: sticky`): в Safari 26 этот приём иногда удерживает нижнюю плавающую панель прозрачной вместо непрозрачной заливки; на остальных браузерах элемент скрыт.

**Ограничение Safari:** область непосредственно под его нижними системными кнопками контролирует браузер, и Safari может закрашивать её одним цветом, даже когда у страницы градиент. Полную прозрачность или непрерывную анимацию за нативной панелью нельзя гарантировать средствами CSS/JavaScript. В Safari больше нет отдельного сплошного *фона сайта*, но конечный вид системной области нужно проверить на iPhone с iOS 26; для полностью свободного от браузерных панелей режима можно добавить сайт на экран «Домой» как веб-приложение.

## Архитектура

- **Vue 3** (Composition API, `<script setup>`), **Vite**, **TypeScript strict**.
- **Vue Router 4**: страницы загружаются лениво, переход к финалу закрыт до прохождения всех вопросов.
- **Pinia**: централизованное состояние квеста и настроек.
- **CSS + design tokens**: композиция, доступность, mobile-first оформление.
- **Nunito**: загружается через Google Fonts, при недоступности — системный fallback. Сайт остаётся работоспособным без сети после установки зависимостей.
- **Vitest**, **ESLint**, **vue-tsc**, **Prettier**.

```text
src/
├── components/
│   ├── layout/       # Шапка, подвал
│   ├── quest/        # Вопросы и воспоминания
│   └── ui/           # Слайдер, стекло, настройки, иконки
├── composables/      # Тема и focus management
├── data/             # Вопросы, варианты, ответы и главы
├── router/           # Маршруты и ограничения доступа
├── stores/           # Состояние квеста и настроек
├── styles/           # Токены, общие и экранные стили
├── types/            # Типы модели
├── utils/            # Хранилище и геометрия слайдера
├── views/            # Четыре экрана
├── App.vue
└── main.ts
```

## Кастомизация

- Тексты вопросов, правильные варианты и пояснения: `src/data/quest.ts`.
- Текст поздравления: `src/views/BirthdayView.vue`.
- Основные цвета, размеры, тени и стекло: `src/styles/tokens/index.css`.
- Движущиеся градиенты обеих тем: `src/styles/base/global.css`.
- Ползунок и заливка: `src/components/ui/SlideAction.vue`, `src/utils/slideGeometry.ts`, `src/styles/components/chrome.css`.
- Розовое конфетти: `src/components/ui/BirthdayConfetti.vue` и `src/styles/components/birthday.css`.

Для публикации выполните `npm run build` и разместите содержимое `dist/` на статическом хостинге. Для GitHub Pages используются hash-маршруты; перенаправления для вложенных URL не требуются.

## Публикация на GitHub Pages

Подготовлена автоматическая публикация в репозиторий `BottomSheet/discard` через `.github/workflows/deploy.yml`. После отправки файлов в GitHub и включения **Settings → Pages → Source: GitHub Actions** сайт будет доступен по адресу `https://bottomsheet.github.io/discard/`.

Для GitHub Pages используется `base: '/discard/'` при сборке и hash-маршрутизация в Vue Router, чтобы обновление внутренних страниц не давало ошибку 404. Подробная инструкция: [DEPLOY.md](./DEPLOY.md).
